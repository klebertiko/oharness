# How to configure

Anthropic subscription

1. Install the `claude` command and make sure it is on your PATH.
2. In Forja, open Providers and choose the Anthropic account.
3. Choose Entrar. A terminal opens with `claude login`.
4. Finish sign-in in that window. Forja notices the session and tests the connection.

Forja does not read or store the session token. The plan name is shown only when it is one of Pro, Max, Plus, Team, Free, Enterprise, Business, or Ultra.
