# ADR 0063: Factory MCP

Status: aceita (implementação no PR do MCP). Conceitos de: docs.warp.dev/factories/factory-mcp (enviar trabalho, assumir localmente, devolver à mesma tarefa, avisar o foreman, aviso de que assumir não trava a tarefa); desenho próprio e **local**.

## Decisão
- Servidor MCP local, **stdio** (`oharness factory mcp`), JSON-RPC 2.0 mínimo (`initialize`, `tools/list`, `tools/call`) escrito à mão, sem dependência nova. Sem rede: um transporte HTTP só entraria com ADR próprio. O cliente (Claude Code, Codex, Cursor...) inicia o servidor como processo filho, então ele roda como o dono e fala com a fábrica pela mesma `FactoryPort` da CLI; sem token. Por isso a superfície é pequena e fixa, e mesmo assim limitada por posse: `cancel` só vale para itens que o próprio cliente criou (`source.kind = mcp`, ref `mcp:<cliente>:…`) e `release` só para o mesmo cliente que fez o `claim` (holder `mcp/<cliente>/<sessão>`); o cliente é o `clientInfo.name` do `initialize` (exigido antes de qualquer ferramenta), então duas sessões do mesmo agente do dono se enxergam — a fronteira é entre agentes diferentes, não entre sessões.
- **Ferramentas** (todas na classe agente/integração, ADR 0059): `factory_submit` (colocar trabalho: título + nota; para continuar trabalho local, a nota referencia a branch/PR já publicado), `factory_list`, `factory_status` (item, runs, artefatos, conversa), `factory_search`, `factory_comment` (guiar a sessão do foreman: progresso, pergunta, bloqueio), `factory_cancel`, `factory_metrics`, `factory_inbox` (itens `awaiting_human`, só leitura), `factory_claim` e `factory_release`.
- **Assumir de verdade:** diferente de um MCP que não trava a tarefa, `factory_claim` muda o item para `claimed`, **suspende a run da fábrica** (continuável) e devolve o contexto do item e **comandos git sugeridos** para preparar um worktree isolado num clone local (supõem o remoto `origin`; se a branch `factory/<id>` já existe de uma devolução anterior, o comentário dos comandos diz o que usar). O MCP **não modifica arquivos**; o agente (ou `oharness factory claim --worktree`) executa a preparação. Outro `claim` num item assumido é recusado.
- **Devolver:** `factory_release {summary, branch?, status}` com a branch **já publicada** (nome de ref simples: não começa com `-`, sem espaço, `..` nem metacaracteres); o item volta a revisão (`needs_review`) ou à fila (`abandoned`) e o foreman decide o próximo passo. Não conclui o item e não há ferramenta de merge. `done` vem de merge observado ou confirmação humana (A).
- **Fora do alcance do MCP, por construção:** aprovar spec, responder pergunta de checkpoint, `confirm_merged`, ativar/reverter definição (classe humana). Sem ferramenta de execução de comando, de push ou de leitura de credencial; tokens não passam pelo MCP.
- **Dados de fora são dados:** todo texto que uma fonte pode ter escrito (título, `ref`, urls, holder, PR) sai das ferramentas sob `untrusted`, dentro de `fence_untrusted`, com segredos redigidos e a cerca não forjável; ids e estados ficam como são. `factory_status` devolve o item (runs, artefatos e conversa ficam para a API do A); a busca casa o título já redigido e diz se olhou só os 200 mais novos (o `instructions` do `initialize` também avisa o modelo); argumentos são validados por JSON Schema (campos desconhecidos recusados), linhas passam de 1 MiB são recusadas, há limite de taxa (ADR 0059) e viram comentário/item não confiável.
- **Notificação** (rota de aviso a Slack/Linear ao terminar): fora deste corte.

## Não verificado
Interoperabilidade com clientes reais (Claude Code, Codex, Cursor) — testado com um cliente JSON-RPC de teste sobre stdio. Verificar localmente com `claude mcp add`.

## Detalhes de protocolo
stdout é o canal do protocolo: a CLI o reserva e redireciona qualquer `print` alheio para stderr; JSON sai só em ASCII; stdin é UTF-8 com bytes inválidos substituídos. Uma mensagem ruim (JSON profundo, forma inesperada) nunca derruba a sessão. Reenviar a mesma `ref` depois que o trabalho terminou cria trabalho novo; uma segunda nota numa `ref` ainda aberta vira comentário.
